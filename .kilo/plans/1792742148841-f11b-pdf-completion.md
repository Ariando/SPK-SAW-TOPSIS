## 2. Cacat yang harus diperbaiki

### C1. Allowlist halaman bisa dilewati dengan path traversal

Di `app/src/pages/api/pdf.ts:15-17`, `isAllowedPath` memeriksa string mentah:

```ts
const ALLOWED_PREFIXES = ['/hasil/', '/hasil/bandingkan', '/ahp/', '/sensitivitas'];
function isAllowedPath(pathname: string) {
  return ALLOWED_PREFIXES.some((prefix) => pathname === prefix || pathname.startsWith(prefix));
}
```

Nilai `halaman=/hasil/../kriteria` lolos pemeriksaan karena berawalan `/hasil/`. Setelah `new URL(target, origin)` URL dinormalkan menjadi `/kriteria`, dan pemeriksaan kedua (`absoluteUrl.startsWith(url.origin)`) juga lolos karena origin tidak berubah. Akibatnya halaman di luar allowlist tetap bisa dicetak.

Perbaikan: normalkan path lebih dulu, lalu periksa `pathname` hasil normalisasi, bukan string mentah.

```
const normalized = new URL(target, 'http://placeholder').pathname;
```

Periksa `normalized` terhadap allowlist, dan tolak bila `target` mengandung `..` sebelum normalisasi.

### C2. Halaman sensitivitas tidak punya tombol PDF

Endpoint sudah mengizinkan `/sensitivitas`, dan uji `verify-pdf.mjs:197-201` sudah membuktikan endpoint bekerja. Tetapi pengguna tidak bisa menemukannya: `/sensitivitas` hanya punya tautan "Buka halaman hitung" di slot `actions`.

Perbaikan: tambahkan tautan "Unduh PDF" di `Fragment slot="actions"` pada `app/src/pages/sensitivitas/index.astro:52-54`, dengan parameter yang mencerminkan analisis yang sedang tampil (metode, delta, skenario, merata).

### C3. `closeBrowser` tidak pernah dipanggil

`app/src/lib/pdf/render.ts:61-66` mengekspor `closeBrowser`, tetapi tidak ada pemanggil di seluruh repo. Peramban dipakai ulang lewat `sharedBrowser`, sehingga proses Chromium tetap hidup sampai proses Node berakhir. Pada mode dev dengan restart berulang, ini meninggalkan proses yatim.

Perbaikan: panggil `closeBrowser` pada `process.on('SIGINT')`, `SIGTERM`, dan `beforeExit`. Bila tidak ingin menambah hook proses, hapus fungsi dan pakai satu peramban per permintaan dengan biaya 1 sampai 2 detik per PDF.

### C4. Label tombol tidak sesuai perilaku

`content-disposition` memakai `inline`, artinya peramban menampilkan PDF di tab, bukan mengunduh. Label tombol berbunyi "Unduh PDF". Salah satu harus menyesuaikan.

## 3. Keputusan yang diusulkan

| Kode | Keputusan | Alasan |
|---|---|---|
| D1 | `content-disposition: attachment` | label tombol "Unduh PDF" berarti berkas disimpan. Untuk lampiran skripsi, berkas yang tersimpan lebih berguna daripada tab yang harus disimpan manual |
| D2 | Tombol sensitivitas membawa seluruh parameter analisis | PDF harus sama dengan yang terlihat di layar, termasuk metode, delta, dan sumber bobot |
| D3 | `closeBrowser` tetap dipertahankan, dipanggil pada sinyal proses | peramban bersama menghemat 1 sampai 2 detik per permintaan, tetapi harus ditutup rapi |

Bila D1 ingin diubah menjadi `inline`, label tombol harus diganti "Buka PDF".

## 4. Urutan pekerjaan

1. **Perbaiki `isAllowedPath`** di `app/src/pages/api/pdf.ts`. Normalkan path sebelum diperiksa, tolak `..`, dan periksa hasil normalisasi terhadap allowlist. Jangan mengubah daftar halaman yang diizinkan.
2. **Ubah `content-disposition`** menjadi `attachment`.
3. **Tambahkan tautan PDF** di `app/src/pages/sensitivitas/index.astro`, di dalam `Fragment slot="actions"`, dengan `target="_blank"` dan `rel="noopener"`. Bangun URL dari `Astro.url.search` agar parameter yang tidak ada tidak ikut tertulis.
4. **Pasang hook penutupan peramban** pada `SIGINT`, `SIGTERM`, dan `beforeExit` yang memanggil `closeBrowser`.
5. **Tambahkan uji** ke `app/scripts/verify-pdf.mjs`:
   - `halaman=/hasil/../kriteria` ditolak 400
   - `halaman=/sensitivitas/../kriteria` ditolak 400
   - `content-disposition` mengandung `attachment`
   - halaman `/sensitivitas` memuat tautan `/api/pdf?halaman=`
   - tautan sensitivitas membawa `metode` dan `delta`
6. **Dokumentasikan** di `app/README.md`: prasyarat Chrome atau Edge, variabel `PUPPETEER_EXECUTABLE_PATH`, halaman yang boleh diekspor, dan perilaku berkas (unduh, bukan buka di tab).
7. **Perbarui plan** `docs/plan-migrasi-astro.md`: ubah `### F11b. Ekspor PDF (BELUM)` menjadi `(SELESAI <tanggal>)` dengan daftar bukti.

## 6. Risiko

| Risiko | Dampak | Mitigasi |
|---|---|---|
| `puppeteer-core` butuh Chrome/Edge terpasang | PDF gagal di mesin tanpa peramban | endpoint mengembalikan 503 dengan pesan jelas, README mendokumentasikan prasyarat |
| Peramban bersama menumpuk page | memori naik pada banyak permintaan berurutan | setiap permintaan menutup page di blok `finally`, sudah ada |
| Render PDF memblokir permintaan | respons lambat 1 sampai 2 detik | dapat diterima untuk aplikasi lokal, dicatat sebagai batasan |
| Uji PDF bergantung pada data kesebelas metode | uji gagal bila data tidak lengkap | uji sudah menanam data sendiri dan memulihkan seed di akhir |
